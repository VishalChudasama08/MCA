👉 “Secure User Management System Based on OWASP Principles (Desktop Application)”

📌 1. Project Overview / Abstract (ready to copy)

	This project presents a Secure User Management System developed as a desktop application using Java AWT/Swing and MySQL database with JDBC connectivity. The system focuses on implementing secure authentication mechanisms based on OWASP security principles, particularly secure password storage using BCrypt hashing and prevention of SQL Injection using PreparedStatement.
	
	The application provides functionalities such as secure user registration, login, profile management, password recovery, and admin-based user monitoring. The objective of the project is to demonstrate how traditional desktop applications can be designed with modern cybersecurity best practices while maintaining simplicity and usability.

📌 2. Problem Statement (important for report)

   Most beginner-level applications store user passwords in plain text and use unsafe SQL queries, making them vulnerable to cyber-attacks such as:
		SQL Injection
		Password theft
		Unauthorized access
		Data manipulation
	This project solves these issues by introducing secure coding practices in a Java-based desktop application.

📌 6. Database Design (VERY IMPORTANT for viva)

Create this table in MySQL:

CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100) UNIQUE,
    password VARCHAR(255),
    phone VARCHAR(15),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);


Explain in viva:
