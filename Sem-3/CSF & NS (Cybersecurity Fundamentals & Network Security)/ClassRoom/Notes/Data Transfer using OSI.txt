| OSI Layer       | What happens to data?                                | Data Unit / PDU        |
| --------------- | ---------------------------------------------------- | ---------------------- |
| 7. Application  | Application creates data                             | Data                   |
| 6. Presentation | Formatting, encoding, encryption, compression        | Data                   |
| 5. Session      | Manages communication session                        | Data                   |
| 4. Transport    | Adds TCP/UDP information                             | Segment / Datagram     |
| 3. Network      | Adds IP information                                  | Packet                 |
| 2. Data Link    | Adds MAC information and error detection             | Frame                  |
| 1. Physical     | Converts frame into electrical/radio/optical signals | Bits                   |
