CISCO PACKET TRACER - VLAN + ROUTER-ON-A-STICK
====================================================

TOPOLOGY
--------
Router0 G0/0  <---->  Switch0 Fa0/1
PC0 Fa0      <---->  Switch0 Fa0/2
PC1 Fa0      <---->  Switch0 Fa0/3
PC2 Fa0      <---->  Switch0 Fa0/4
PC3 Fa0      <---->  Switch0 Fa0/5


VLAN PLAN
---------
VLAN 10 = HR
VLAN 20 = FINANCE

PC0 = VLAN 10 = 192.168.1.2/24
PC1 = VLAN 10 = 192.168.1.3/24

PC2 = VLAN 20 = 192.168.2.2/24
PC3 = VLAN 20 = 192.168.2.3/24

Router G0/0.10 = 192.168.1.1/24
Router G0/0.20 = 192.168.2.1/24


====================================================
1. CREATE VLAN 10 AND VLAN 20
====================================================

DEVICE: Switch0 -> CLI

enable
configure terminal

vlan 10
name HR
exit

vlan 20
name FINANCE
exit

end

show vlan


====================================================
2. CONFIGURE SWITCH - ACCESS PORTS
====================================================

DEVICE: Switch0 -> CLI

enable
configure terminal

interface range fastEthernet 0/2-3
switchport mode access
switchport access vlan 10
exit

interface range fastEthernet 0/4-5
switchport mode access
switchport access vlan 20
exit

end

show vlan


PORT MAPPING
------------
Fa0/2 -> PC0 -> VLAN 10 (HR)
Fa0/3 -> PC1 -> VLAN 10 (HR)
Fa0/4 -> PC2 -> VLAN 20 (FINANCE)
Fa0/5 -> PC3 -> VLAN 20 (FINANCE)


====================================================
3. CONFIGURE ROUTER
====================================================

DEVICE: Router0 -> CLI

enable
configure terminal

interface gigabitEthernet 0/0
no shutdown
exit

interface gigabitEthernet 0/0.10
encapsulation dot1Q 10
ip address 192.168.1.1 255.255.255.0
exit

interface gigabitEthernet 0/0.20
encapsulation dot1Q 20
ip address 192.168.2.1 255.255.255.0
exit

end

show ip interface brief


====================================================
4. CONFIGURE SWITCH ROUTER PORT AS TRUNK
====================================================

IMPORTANT:
Your actual Router0-to-Switch0 connection is:

Router0 G0/0 -> Switch0 Fa0/1

Therefore Fa0/1 must be the trunk.

DEVICE: Switch0 -> CLI

enable
configure terminal

interface fastEthernet 0/1
switchport mode trunk
exit

exit

show interfaces trunk


====================================================

====================================================

PC0:
Desktop -> IP Configuration

PC1:
Desktop -> IP Configuration

IP Address:      192.168.1.3
Subnet Mask:     255.255.255.0
Default Gateway: 192.168.1.1


PC2:
Desktop -> IP Configuration

IP Address:      192.168.2.2
Subnet Mask:     255.255.255.0
Default Gateway: 192.168.2.1


PC3:
Desktop -> IP Configuration

IP Address:      192.168.2.3
Subnet Mask:     255.255.255.0
Default Gateway: 192.168.2.1


====================================================
6. VERIFY SWITCH CONFIGURATION
====================================================

DEVICE: Switch0 -> CLI

enable

show vlan brief

Expected:

VLAN 10 = HR
Fa0/2, Fa0/3

VLAN 20 = FINANCE
Fa0/4, Fa0/5


Check trunk:

show interfaces trunk

Expected trunk:

Fa0/1


====================================================
7. VERIFY ROUTER CONFIGURATION
====================================================

DEVICE: Router0 -> CLI

enable

show ip interface brief

Expected:

GigabitEthernet0/0       up
GigabitEthernet0/0.10   up
GigabitEthernet0/0.20   up


====================================================
8. TEST CONNECTIVITY
====================================================

PC0 -> Desktop -> Command Prompt

Test Router VLAN 10:

ping 192.168.1.1

Test PC1:

ping 192.168.1.3

Test PC2 (INTER-VLAN):

ping 192.168.2.2

Test PC3 (INTER-VLAN):

ping 192.168.2.3


PC2 -> Command Prompt

ping 192.168.2.1

ping 192.168.2.3

ping 192.168.1.2


====================================================
9. SHOW PACKET TRANSFER IN PACKET TRACER
====================================================

1. Click Simulation Mode at the bottom-right.
2. Select Add Simple PDU (envelope icon).
3. Click PC0.
4. Click PC2.
5. Click Capture/Forward.

Packet path:

PC0
  |
  v
Switch0
  |
  | VLAN 10
  v
Router0
  |
  | VLAN 20
  v
Switch0
  |
  v
PC2

This demonstrates INTER-VLAN ROUTING.


====================================================
IMPORTANT NOTE ABOUT THE BOARD
====================================================

The board shows an example using:

interface fastEthernet 0/5
switchport mode trunk

But in YOUR Packet Tracer topology, Fa0/5 is connected to PC3.

Your actual connections are:

Fa0/1 = Router0 G0/0
Fa0/2 = PC0
Fa0/3 = PC1
Fa0/4 = PC2
Fa0/5 = PC3

Therefore:

Fa0/1 = TRUNK
Fa0/2-3 = ACCESS VLAN 10
Fa0/4-5 = ACCESS VLAN 20

Do NOT make Fa0/5 a trunk because PC3 is connected to Fa0/5.
